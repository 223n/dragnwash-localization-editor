# Security

**[日本語](SECURITY.md)** | English

## Reporting a vulnerability

If you find a vulnerability, please do not write about it in a public issue.
This gives us time to fix it before it can be exploited.

Open the "Security" tab on GitHub, choose "Report a vulnerability" and report it privately.
If private reporting is not enabled on this repository, contact the repository owner directly.

## What to include in your report

- The affected versions or commits
- Steps to reproduce it
- The impact you think it could have

## How we respond

1. We reply to confirm that we received your report
1. We check the details and work out how far the impact reaches
1. We prepare a fix and publish it

Please do not disclose the contents of your report until the fix is published.

## Supported versions

Only the latest release is covered.
We do not backport fixes to older releases.
